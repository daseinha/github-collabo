# Contact Page

고객 문의를 받기 위한 연락처 페이지 프로젝트입니다. 이름, 이메일, 전화번호, 문의 유형과 내용을 입력할 수 있는 반응형 정적 HTML 예제입니다.

## 프로젝트 개요

이 프로젝트는 서비스 이용자가 궁금한 점을 빠르게 남길 수 있도록 만든 문의 페이지 예제입니다. 별도의 빌드 과정 없이 HTML 파일 하나로 동작하므로 누구나 쉽게 수정하고 테스트할 수 있습니다.

## 포함된 기능

- 이름 입력 필드 (필수)
- 이메일 입력 필드 (형식 검증 포함)
- 전화번호 입력 필드 (선택)
- 문의 유형 선택 드롭다운
- 문의 내용 텍스트 영역
- 제출 버튼 및 다시 작성 버튼
- 회사 위치 및 연락처 안내 영역

## 파일 구조

```text
github-collabo/
├── contact.html   # 문의 폼 페이지
├── README.md      # 프로젝트 설명 문서
├── .gitignore     # Git 제외 파일 목록
└── .git/          # Git 저장소
```

## 페이지 구성

현재 `contact.html`에는 다음 요소가 포함되어 있습니다.

- 상단 타이틀: "문의하기 (Contact Us)"
- 문의 입력 폼
- 회사 소개 및 오시는 길 영역
- 주소, 대표 전화번호, 대표 이메일, 운영 시간 표시

## BBB 브랜치 작업 내용

BBB 브랜치에서는 다음과 같은 작업을 진행했습니다.

- 문의 폼의 입력 항목을 정리하고 문의 유형 선택 항목을 추가함
- 이메일 형식 검증과 필수 입력 표시를 적용함
- 회사 정보 영역에 운영 시간과 오시는 길 안내를 추가함
- `main` 브랜치의 변경 사항을 확인한 뒤 작업을 시작함
- README의 프로젝트 설명과 작업 내용을 새로 정리함
- 충돌(conflict) 발생 상황을 직접 만들어 해결하는 과정을 실습함

## 실행 방법

1. 저장소를 클론합니다.
2. 작업할 브랜치로 이동합니다.
3. 브라우저에서 `contact.html` 파일을 열어 화면을 확인합니다.
4. 문의 폼에 값을 입력하고 동작을 점검합니다.

예시:

```bash
git clone <repository-url>
cd github-collabo
git checkout BBB
# 브라우저에서 contact.html 열기
```

## 작업 목적

이 프로젝트는 Git 협업 실습용으로, 같은 파일을 서로 다른 브랜치에서 수정했을 때 발생하는 충돌을 확인하고 해결하는 연습을 목적으로 합니다.

## 참고

본 페이지는 교육용 예제이며, 폼 전송 처리나 서버 연동은 포함되어 있지 않습니다. 실제 운영 환경에서는 별도의 백엔드 구현이 필요합니다.
