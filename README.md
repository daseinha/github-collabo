# Contact Page

간단한 문의 폼 페이지 프로젝트입니다. 사용자가 이름, 이메일, 연락처, 문의 내용을 입력할 수 있는 연락처 페이지를 구성한 정적 HTML 예제입니다.

## 프로젝트 개요

이 프로젝트는 회사 또는 서비스에 대한 문의를 받을 수 있도록 간단한 연락처 페이지를 구현한 예제입니다. HTML만으로 구성되어 있어 빠르게 열람하고 수정할 수 있습니다.

## 포함된 기능

- 이름 입력 필드
- 이메일 입력 필드
- 연락처 입력 필드
- 문의 내용 텍스트 영역
- 전송 버튼 및 초기화 버튼
- 회사 정보 영역 표시

## 파일 구조

```text
github-collabo/
├── contact.html   # 문의 폼 페이지
├── README.md      # 프로젝트 설명 문서
├── .gitignore     # Git 제외 파일 목록
└── .git/          # Git 저장소
```

## 페이지 구성

현재 `contact.html`에는 다음 요소가 포함되어 있습니다.

- 상단 안내 문구: "Contact Us"
- 사용자 입력 폼
- 회사 정보 영역
- 주소, 전화번호, 이메일 표시

## 실행 방법

1. 저장소를 다운로드하거나 클론합니다.
2. 브라우저에서 `contact.html` 파일을 엽니다.
3. 입력 폼에 정보를 작성하고 제출해 봅니다.

예시:

```bash
git clone <repository-url>
cd github-collabo
# 브라우저에서 contact.html 열기
```

## 작업 목적

이 프로젝트는 협업 연습용으로 구성되었으며, Git 브랜치 관리와 README 작성, 정적 웹 페이지 구성 등을 실습하는 데 목적이 있습니다.

## 참고

본 페이지는 교육용 예제로 제작되었고, 실제 서비스 운영을 위한 폼 전송 로직이나 서버 연동은 포함되어 있지 않습니다.
